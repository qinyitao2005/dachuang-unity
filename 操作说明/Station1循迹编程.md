# Station1 示教器循迹编程

实际探针接近纸面零位（Z≤0.5 mm）时，界面会显示一秒红色碰撞警示；探针重新抬高到离纸超过 2 mm 后才会再次触发。提示不会自动停止机械臂，现实操作须确认安全间隙并保护设备。

主场景：`Assets/RoboticsLab/Scenes/RoboticsTrainingRoom.unity`。

本功能记录第一台机械臂真实探针尖端的位置，以 L 直线、C 三点圆弧执行循迹，最后返回示教的安全点，不生成新笔迹。Station1 程序与其他工位分开保存。

## 从新建程序开始

1. 进入 Station1 工位后，示教器自动显示；首次进入时显示 SELECT PROGRAM 程序列表。已有程序可能恢复到编辑页，可按 SELECT 进入列表。
2. 按 F2 CREATE，新建名称默认是 TRACE001 等未使用名称。可以直接接受，也可用键盘输入英文字母、数字和下划线。按 F1 END 或 ENTER 完成创建。重名时不会覆盖旧程序。
3. 点动到自己选择的安全点，至少高于纸面 5 mm；建议在绿色起点正上方约 18 mm。
4. 松开 SHIFT（鼠标锁定时再次点击 SHIFT）。按 F1 POINT，选择 L，ENTER。**确认菜单时就记录当前位置**，形成第一条 L P[1]。
5. 按住或鼠标锁定 SHIFT；移动到纸面循迹起点，SHIFT + F1 记录 L P[2]。同样的方法继续记录直线终点。
6. 要换成 C：先移动到圆弧经过点，松开 SHIFT，F1 POINT 选 C、ENTER，记录经过点。重新按住/锁定 SHIFT，移动到圆弧终点，SHIFT + F5 TOUCHUP 补齐终点。这两个点共同组成一条 C 指令，起点取上一条运动的终点。
7. 连续录下一条 C 时，保持 SHIFT，到新的经过点按 F1，到终点按 F5。经过点不是圆心。
8. 到程序末尾 [End]，输入 1、ENTER，追加 L P[1]，引用开头的同一个安全点。这个便利操作直接添加 L，不会重新录点，也不受当前默认 L/C 类型影响。
9. 用上下键把光标移到第一条 L P[1]。需要单步则打开 STEP；连续执行则关闭 STEP。保持 SHIFT 后按 FWD。

进入工位时示教器自动显示；已有程序可在列表中用上下键选择、ENTER 打开。程序录点、修改后自动保存，退出工位时也会保存。标题的 * 表示有尚未落盘的修改，保存失败会显示“未保存”，不切换到其他程序。

保存目录：Application.persistentDataPath/PendantPrograms/Station01。程序列表可以重新打开之前保存的文件。速度与本实验固定速度不符的文件会被拒绝加载，不会偷偷修改它的速度。

## 按键

| 按键 | 当前行为 |
|---|---|
| SELECT | 程序列表；F2 CREATE 新建，ENTER 打开选中程序。手柄 Menu 在列表中用于退出工位。 |
| SELECT → 选中程序 → F3 DELETE | 弹出程序名确认页；F4 YES 删除整个程序及其点位文件，F5 NO 或 PREV 取消。F3 在编辑页不删除单行。 |
| PREV | 返回编辑页；新建中可取消返回。手柄 View 短按对应 PREV。 |
| SHIFT | 键盘按住使用；鼠标点击锁定，再点松开，绿色表示有效。 |
| ±X / ±Y / ±Z（J1/J2/J3 所在三行） | SHIFT 有效时按住点动，松开或移开鼠标停止。键盘也可用 SHIFT 配合 WASD、Q/E。上下左右方向键只导航程序，不点动。 |
| F1 POINT（SHIFT 松开） | 打开默认 L/C 菜单；上下选择、ENTER **选择并记录当前位置**。在 End 追加录点。 |
| SHIFT + F1 POINT | 重复当前默认类型：L 记录终点，C 记录经过点。 |
| SHIFT + F5 TOUCHUP | 补齐选中未完成 C 的终点，或更新选中程序行引用的点。 |
| 上下键 | 选择程序行或 End；运行/暂停时禁止移动编辑光标。 |
| 左右键 | C 行中选择经过点/终点，供 TOUCHUP 或数字引用使用。 |
| 数字 + ENTER | 选中行时修改对应点的引用；End 时追加引用已有点的 L。 |
| F4 CHOICE | 选中已有行时显示，用于修改该行运动类型；End 不显示。 |
| SHIFT + FWD | 新运行从选中行开始；HOLD/单步暂停后继续已有进度。End 不运行。 |
| STEP | 开关单步模式；一个完整的 C（经过点和终点）算一条指令。 |
| HOLD | 暂停并保留当前行、轨迹进度。 |
| FCTN → 1 ABORT → ENTER | 终止执行，保留点位和程序。之后可重新选择起始行。 |
| FCTN → 2 删除最后一行 → ENTER | 停止后删除末行；全部删完后，点号从 P[1] 重新开始。 |
| RESET | 复位已排除的故障，不代替 ABORT，不终止正常运行或 HOLD 状态。 |
| 急停 | 急停后先解除，再 RESET，然后 SHIFT + FWD 明确继续。 |
| 调速键 | 不接入调速。运动指令固定 20 mm/sec、FINE；保持原有工位速度上限与手动点动速度。 |

录点只记录点位，不记录用户点动时经过的整段路线。回放根据 L/C 指令生成直线和圆弧。实际运动继续使用已有 IK、工作区、碰撞和真实末端跟随检查。

## 程序示例：一段直线、一段半圆，再返回

```text
1:L P[1] 20mm/sec FINE
2:L P[2] 20mm/sec FINE
3:L P[3] 20mm/sec FINE
4:C P[4] P[5] 20mm/sec FINE
5:L P[1] 20mm/sec FINE
[End]
```

- P[1]：安全点；P[2]：纸面起点；P[3]：直线终点、圆弧起点。
- 一条 C 从 P[3] 出发，经过 P[4] 到 P[5]，可以完成标准半圆。
- 末行从 P[5] 直线返回保存的 P[1]，没有额外的强制离开点。安全点、接近和返回的离纸运动不计入纸面覆盖率。
- 单条 C 是圆弧，不是任意曲线；当前 J 参考线的底部是椭圆形，分段 C 仅是近似，不保证与该参考线完全重合。

## 保留的教学简化

- “首行 L P[1]、P[1] 高于纸面至少 5 mm、末行 L P[1]”是本课堂的验收条件，不是 FANUC 所有程序的统一限制。
- 固定竖直探针姿态、纸面中心 USER 原点。LCD 的 X/Y 是纸面坐标，Z 是离纸高度，单位 mm。没有实现完整坐标系标定、关节运动、姿态编辑、硬件使能回路。
- SHIFT 鼠标锁定、程序名键盘输入、自动保存、End 输入点号追加 L 是便于操作的简化。
- 新录点暂时只追加到 End；修改已有位置用 TOUCHUP。C 改 L 会拆成经过点和终点两条 L；L 改 C 只支持末行且不能是首条安全点，原终点成为经过点，之后补齐终点。
- 从中间 L 开始会由当前真实位置直线到该行终点。从 C 行开始前，实际探针需先到上一行终点；否则提示先执行上一行，避免悄悄改变圆弧起点。
- 程序执行或暂停期间锁定编辑、手动点动和预设自动循迹。
