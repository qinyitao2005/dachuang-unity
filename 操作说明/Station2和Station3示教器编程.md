# Station2 套圈、Station3 画图：示教器 L/C 编程

日期：2026-11-09。适用工程：仓库主项目。主场景：`Assets/RoboticsLab/Scenes/RoboticsTrainingRoom.unity`。

02、03 工位现在使用组员为第一台设计的 SELECT、POINT、TOUCHUP、SHIFT、FWD 工作流。本文是第二、第三台的正式操作步骤；第一台的课堂安全点和评分要求仍见 [Station1 循迹编程](Station1循迹编程.md)。

## 从哪里打开

完成安全帽、右墙教学和问答后，进入 02 或 03 工位会直接显示示教器。LCD 标题中的 `S2` 或 `S3` 表示当前工位。三台各有独立的程序、名称和保存目录，切换工位不会套用另一台的点位。Xbox 手柄步骤分别见 [Station2](Station2_Xbox手柄.md)和 [Station3](Station3_Xbox手柄.md)。

## 新建、录点和运行

1. 按 SELECT 进入程序列表，再按 F2 CREATE。第二台默认命名 `RING001`，第三台默认 `DRAW001`；可用英文字母、数字、下划线命名。按 F1 END 或 ENTER 创建，重名不会覆盖。
2. 按住键盘 SHIFT，或点击控制器 SHIFT 锁定为绿色，再用 ±X/±Y/±Z 点动。键盘也可用 SHIFT 配合 WASD、Q/E；上下左右方向键只选择程序行和点引用。
3. 移到起点后松开 SHIFT；若用鼠标锁定，再点一次 SHIFT 松开。按 F1 POINT，选 L，ENTER。**确认时立即记录真实工具位置**，形成首条 `L P[1]`。
4. 移动到下一条直线的终点，保持 SHIFT，按 F1 追加 L。新点只追加到 `[End]`，已有位置用 TOUCHUP 修改。
5. 录圆弧时，先移到圆弧经过点。松开 SHIFT，F1 POINT 选 C，ENTER，先记录经过点；再按住或锁定 SHIFT，移到圆弧终点，按 F5 TOUCHUP 补齐。C 的起点是上一条运动的终点，经过点不是圆心。
6. 默认类型已是 C 时，SHIFT + F1 记录下一段经过点，SHIFT + F5 补终点。要重新录 L，松开 SHIFT，用 F1 菜单选 L 并 ENTER。
7. 用上下键选中要开始的程序行。关闭 STEP 可连续运行；开启 STEP 则一次执行一条完整 L/C。保持 SHIFT 后按 FWD。光标在 `[End]` 时不会启动。

只录经过点的 C 显示 `P[?]`，必须补终点才能运行。单个 C 是三点圆弧，不能直接表示任意曲线或整圆；三点共线、重合或圆弧越出工作区时会提示拒绝运行。从 C 行直接开始前，实际工具必须已到上一行终点，否则先运行上一行。

## 第二台：套圈

- 记录的是**实际圆环中心**在工位中的位置。USER 原点使用套圈工作区中心，LCD 的 X/Y/Z 分别表示左右、前后、升降，单位 mm。
- 首行用 L。第二台不采用第一台“高于纸面至少 5 mm”和“末行必须返回 P[1]”的课堂要求，也没有抬笔/落笔。
- 先在钢丝上选取可达起点，再沿合法走向分段录 L/C。录点只保存位置，不会记录点动时绕过障碍的完整路线。
- 程序仍受钢丝两端、圈缘和机械臂碰撞约束。若直线或圆弧会穿过钢丝、支架或机身，执行会被阻挡或报错。可 HOLD 暂停；需要修改轨迹时先 ABORT，再分段重录。不要把“回到 P[1]”理解成自动沿钢丝倒退。
- 不需要强制回原点。确实需要返回时，应自行示教合法的返回路径；在 End 输入 `1`、ENTER 只会追加直线 `L P[1]`，不会自动避障。

## 第三台：按笔尖高度留线

Station3 沿用第一台“安全点 → L/C 轨迹 → 返回同一安全点”的课堂流程。安全点 P[1] 必须高于纸面至少 **15 mm**。笔尖真实位置距离纸面 **0–10 mm** 时，手动点动和程序复现都在纸上留线；高于 10 mm 时正常移动但不留线。无需 IO 或 P 切换笔状态。旧程序里的 UP/DOWN 标志不再决定是否画线。

推荐示例：

1. 在高于纸面至少 15 mm 的位置录首条 `L P[1]` 安全点。
2. 降到纸上图形的起点，录 `L P[2]`；接近纸面的最后 10 mm 会有笔迹。
3. 沿直线移到终点，录 `L P[3]`。
4. 移到圆弧经过点，选 C 并 ENTER 录 `P[4]`；移到弧终点，按 SHIFT+F5 TOUCHUP 录 `P[5]`。
5. 将光标移到 `[End]`，按 `1`、ENTER，追加 `L P[1]`。最后的返回路径在离纸前的 10 mm 内仍可能留线；若不想要连接线，要先示教一段在图形边缘抬高的路径，再返回 P[1]。
6. 用左侧“擦除纸上轨迹”清掉手动示教时留下的草稿。选择首行，保持 SHIFT，按 FWD 复现。程序执行不自动清纸，复现会在原有轨迹上继续留线。

```text
1:L P[1] 20mm/sec FINE    安全点，距纸≥15mm
2:L P[2] 20mm/sec FINE    图形起点
3:L P[3] 20mm/sec FINE    直线终点
4:C P[4] P[5] 20mm/sec FINE    圆弧经过点、终点
5:L P[1] 20mm/sec FINE    返回同一安全点
[End]
```

手柄 **Menu 长按 3 秒**或左侧按钮会擦除当前纸上的草稿与复现笔迹，保留程序及点位；运行中擦除也不终止运动，之后笔尖再进入 0–10 mm 范围会重新留线。**View 长按 5 秒**清空当前程序指令和点位，是另一项操作。完整按键见 [Station3 Xbox 手柄说明](Station3_Xbox手柄.md)。

## 修改、暂停和故障处理

| 操作 | 行为 |
|---|---|
| 上下键 | 选择程序行或 End；运行/暂停时不改变编辑光标。 |
| 左右键 | 在 C 行选择经过点或终点。 |
| SHIFT + F5 TOUCHUP | 用真实工具当前位置更新选中的点，或补齐未完成 C 的终点。引用同一点的所有行会使用更新后的位置。 |
| 数字 + ENTER | 已有行修改点引用；End 追加引用该点的 L。 |
| F4 CHOICE | 修改所选行的 L/C 类型；End 不显示。C 改 L 会拆成两条 L；L 改 C 仅支持非首行的末条指令，再补终点。 |
| STEP | 切换单步模式；SHIFT + FWD 执行一整条 L 或 C。 |
| HOLD | 暂停，保留当前行和轨迹进度；SHIFT + FWD 明确恢复。 |
| 松开 SHIFT / 窗口失去焦点 | 运行暂停；再次取得控制后按 SHIFT + FWD 恢复。鼠标锁定 SHIFT 时需再次点击解除。 |
| FCTN → 1 ABORT → ENTER | 终止程序，保留点位和指令，释放手动与编辑控制。 |
| FCTN → 2 删除最后一行 → ENTER | 停止后删除末行；全部删除后，点号重新从 P[1] 开始。 |
| RESET | 复位已排除的故障，不用于终止正常运行或 HOLD 状态。 |
| 急停 | 先解除急停，再 RESET，最后 SHIFT + FWD；不会自动继续。 |
| Esc 退出工位 / 切换工位 | 停止执行并保存，重新进入后需重新选择起始行并运行。Station2/3 的示教器在工位内始终显示。 |

运行与 HOLD 暂停期间不能手动抢控制、录点或修改程序。高级轨迹编辑与示教器的运行/暂停也互斥；先终止当前程序，再切换控制方式。

## 保存和速度

录点和修改后自动保存，关闭、离开、退出时也会保存。标题 `*` 表示尚未落盘；失败时显示「未保存」，不会直接切换到另一个文件。SELECT 可重新打开已保存程序。

- 第二台：`Application.persistentDataPath/PendantPrograms/Station02`。
- 第三台：`Application.persistentDataPath/PendantPrograms/Station03`。

各台可以有同名程序，但文件和点位互不混用。程序在本机用户数据目录，不随 Git 同步。旧版本 100/50/150 mm/sec 的文件不会被新流程悄悄改速；固定速度不符时拒绝加载，需要在新流程重新示教。

三台新示教器均固定 **20 mm/sec、FINE**，没有调速入口。工位原有速度上限、IK 跟随与碰撞约束仍有效，因此真实移动可能低于标称速度。没有加入姿态编辑、完整工业坐标系标定或实体机器人控制。
