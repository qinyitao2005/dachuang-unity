# Station3 画图：Xbox 手柄与示教器

适用范围：主场景第三台画图工位。程序速度固定 20 mm/sec。L/C 的经过点、终点和修改方式见 [Station2/3 编程说明](Station2和Station3示教器编程.md)。

## 进入与移动

完成安全帽、教学和问答后，游荡时靠近 Station3 按 **A**（键盘 **E**）进入。示教器立即显示，左侧有画图状态、擦除纸上轨迹、退出工位按钮；右侧纸面俯视区实时显示实际笔迹和笔尖位置，可点“收起俯视”切换。工位内示教器始终显示。

按住 **RB** 相当于 SHIFT，左摇杆控制 X/Y，RT/LT 升降 Z。笔尖真实位置距纸面 **0–10 mm** 时，手动移动会在纸上留草稿线；高于 10 mm 正常移动但不留线。IO/P 不再切换绘图。左侧状态显示当前距离。

Station3 的实际笔尖接近纸面零位（Z≤0.5 mm）时，会显示一秒红色碰撞警示；抬高到离纸超过 2 mm 后，再次接近才会重新提示。这是提醒窗口，不会自动停止机械臂。Station1 的探针到相同零位时也会提示。

| Xbox | 示教器功能 |
|---|---|
| A / B / X / Y | F1 / F2 / F4 / F5 |
| 十字键上 / 下 | 选择程序或指令行 |
| 十字键左 / 右 | FCTN / ENTER |
| RB | SHIFT，点动及运行使能 |
| LB | FWD，配合 RB 运行 |
| 左摇杆按下 / 右摇杆按下 | 数字 1 / F3 DELETE |
| View 短按 | PREV 返回上一页 |
| View 长按 5 秒 | 清空当前程序的指令和点位 |
| Menu 短按 | 编辑页返回 SELECT PROGRAM；在列表页退出工位 |
| Menu 长按 3 秒 | 擦除 Station3 纸上笔迹，保留程序和点位 |

Menu 的短按在松开时生效；长按到 3 秒只执行擦线，不会先返回列表或退出工位。长按擦线在运行中也能用，运行继续，之后笔尖进入留线范围会重新画。键鼠用户可点左侧“擦除纸上轨迹”。擦线不会移动机械臂。View 清空程序与 Menu 擦线作用不同。

## 从新建程序到复现

1. 在 SELECT PROGRAM 按 **B**（F2 CREATE），再按 **A**（F1 END）使用默认名称；也可键盘输入自定义名称。旧程序可用十字键上下选择，再按右键（ENTER）打开。
2. 将笔尖移到距纸面至少 **15 mm** 的安全位置，按住 RB，按 A（F1）录首条 `L P[1]`。
3. 降到图形起点录 `L P[2]`，沿直线到下一点录 `L P[3]`。录新点时光标放在 `[End]`。
4. 要画圆弧，移到经过点，松开 RB，按 A（F1）选 C，按十字键右（ENTER）录经过点；移动到弧终点，按住 RB，按 Y（F5 TOUCHUP）补终点。
5. 光标移到 `[End]`，按下左摇杆输入 `1`，再按十字键右（ENTER），追加返回安全点的 `L P[1]`。直接从纸面回安全点时，前 10 mm 可能留连接线；需要避开图形时先录一段到边缘再抬高的路径。
6. 用左侧按钮或 Menu 长按 3 秒擦掉教学草稿。选中第一行，保持 RB，按 LB（FWD）运行。运行沿实际 L/C 轨迹走，笔尖落入 0–10 mm 范围时留线。复现开始不自动清除旧笔迹。

运行中需要修改程序：十字键左进入 FCTN，选 `1 ABORT` 并 ENTER。程序列表中，右摇杆按下 F3 可选择删除整个程序；X（F4）确认、Y（F5）取消。HOLD、RESET、急停等专用按钮可直接点击示教器。键盘 Esc 或左侧按钮退出工位。

当前代码已做静态检查与 Unity Roslyn 编译；实际 Play Mode、实物 Xbox 手柄、笔尖高度和回放画面由用户在 Unity 验收。后续验证结果应在 [本次 AI 修改说明](2026-11-14_Station3高度留线与手柄_AI修改说明.md)中更新。
