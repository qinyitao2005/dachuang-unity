# Station1 Xbox 手柄操作

适用范围：Station1 循迹工位。进入工位前的安全帽和教学问答仍按现有界面完成；Station2、Station3 已按相同示教按键逻辑接入，分别见 [Station2 手柄操作](Station2_Xbox手柄.md)与 [Station3 手柄操作](Station3_Xbox手柄.md)。键鼠和鼠标示教器仍可使用。

## 进入与点动

1. 游荡时左摇杆移动、右摇杆转视角；走近安全帽、教学屏或 Station1，按 A 交互。
2. 完成现有安全帽、教学问答前置步骤后，走近 Station1 按 A 进入工位；示教器会直接显示，左侧底部的“退出工位 [Esc]”可返回游荡。
3. 按住 RB（SHIFT），左摇杆左右/前后控制示教器 USER X/Y，RT 升高 Z，LT 降低 Z；松开 RB 即停止手柄点动。探针仍受原有工作区、碰撞和运动限制约束。右摇杆的方向输入在示教器内不点动。

## 示教器按键

| Xbox | 示教器 |
|---|---|
| A | F1 POINT；按住 RB+A 记录当前 L 终点或 C 经过点 |
| B | F2 CREATE（在程序列表中） |
| X | F4 CHOICE |
| Y | F5 TOUCHUP；按住 RB+Y 完成 C 终点或更新点 |
| 十字键上、下 | UP、DOWN，选程序/菜单/程序行 |
| 十字键左、右 | FCTN、ENTER |
| Menu | 在程序编辑等页面进入 SELECT PROGRAM 程序列表；已在 SELECT PROGRAM 时退出工位 |
| View 短按 | PREV，在松开时返回上一层；可从 FCTN 返回编辑页或取消删除确认 |
| 右摇杆按下 | F3；在 SELECT 程序列表中发起删除选中程序 |
| RB 按住 | SHIFT；运行时松开会暂停 |
| 左摇杆按下 | 数字 1，供末尾引用安全点 P[1]，或 FCTN 选 1 ABORT |
| LB | FWD；按住 RB+LB 运行 |
| View 在程序编辑页长按 5 秒 | 调试用：停止执行、清空当前 Station1 程序的全部指令和点位，立即覆盖保存，点号从 P[1] 重来 |

View 短按在松开时触发 PREV；按满 5 秒清空时不会先返回。清空不会删除程序文件和名称。此调试操作不在游戏界面提示，清空前请确认正在编辑目标程序；操作不提供撤销。保存失败时屏幕显示“未保存”。

要从列表中真正删除整个程序：如果正在编辑，先按 Menu 进入 SELECT PROGRAM（如果已经在列表，就不要再按 Menu，否则会退出工位）→ 十字键上下选程序 → 按下右摇杆（F3 DELETE）→ X（F4 YES）确认，或 Y（F5 NO）取消。屏幕会显示待删除的程序名。删除会移除该程序的指令、点位和保存文件；如果删的是当前打开的程序，示教器会回到程序列表。F3 在程序编辑页不会删除单行；现有 `FCTN → 2` 仍只删除最后一行。删除后无法在示教器内撤销。

## 一个完整的 L/C 示例

1. 进入工位后，示教器显示 SELECT PROGRAM；按 B（CREATE）→ A（F1 END），用默认名称新建程序。已有程序可在列表中用十字键上下选择 → 十字键右打开。
2. RB + 左摇杆/RT/LT 移到高于纸面至少 5 mm 的安全点。松开 RB，A 打开 POINT，选 L，十字键右 ENTER，录入 `L P[1]`。
3. 按住 RB 点动到纸面循迹起点，RB+A 录入 `L P[2]`；到直线终点，再 RB+A 录入 `L P[3]`。
4. 到圆弧经过点后松开 RB，A 打开 POINT，十字键下选 C、十字键右 ENTER，录入经过点 P[4]；到圆弧终点后按住 RB+Y，录入终点 P[5]。这是一条 `C P[4] P[5]`。
5. 光标在 `[End]` 时按下左摇杆输入 `1`，十字键右 ENTER，追加 `L P[1]` 返回安全点。
6. 用十字键上移到第一行，按住 RB 并按 LB（FWD），执行程序。运行时必须持续按住 RB；松开会暂停，再按 RB+LB 继续。

课程要求和 L/C 几何细节见 [Station1 循迹编程](Station1循迹编程.md)。程序速度固定为 20 mm/sec；没有接入调速。运行中如需返回列表，先用 FCTN → 1 ABORT 终止程序，再按 Menu。HOLD、RESET、急停等未分配到手柄的专用按键仍可点击示教器；完整正常编程与退出流程可用手柄完成。程序名如需自定义，使用键盘输入。
