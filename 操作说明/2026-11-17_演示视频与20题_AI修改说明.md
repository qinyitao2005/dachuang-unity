## 从哪里打开、怎么操作

### 演示视频

1. 启动主场景或 Windows 演示程序。在漫游或工位界面的左侧，点击“演示视频”。鼠标被漫游锁定时，可先按 Tab 释放光标。
2. 漫游时默认显示“三工位完整演示”；在 01/02/03 工位中打开时，默认显示该工位单片。上方标签可切换合辑、循迹、套圈或画图。
3. 视频加载后播放。点击播放/暂停或按空格控制视频，点击“从头播放”重播。
4. 点击“返回实操”或按 Esc 关闭。观看期间实训运动暂停，当前工位、程序和点位保留；原先运行中的程序保留暂停进度，返回后由操作者保持 SHIFT 再按 FWD 明确继续。
5. 视频窗口打开期间，操作键作用于视频窗口，不应点动、录点、切换工位或启动后台程序。

墙上教学流程仍是第一部分看视频、第二部分答题。第一部分改用三工位合辑，合辑与三个单片使用同一批最新工程录制素材。

### 20 题知识问答

1. 进入右墙的知识问答页。顶部显示当前题号和总数 20，每题有 A/B/C/D 四个选项。
2. 先自行作答；需要提示时，把鼠标移到右下方“正确答案已遮盖”卡片上，查看正确字母及选项全文。鼠标移开后答案重新隐藏，切换题目也会恢复遮盖。
3. 查看提示不会自动选择答案、提交或跳题。仍须点击选项；答错可继续尝试，答对显示解析。
4. 点击左下方“下一题”，最后点击“完成问答”。完成全部问答后按原流程进入实操工位。
5. 如需直接展示实操，点击底部中间“跳过全部20题，去实操”。任意题均可跳过剩余题目，立即解锁三台机械臂；已答对题数保留，不把剩余题计为答对，完成页明确显示“问答已跳过”。重新答题并全部完成后恢复正常通过状态。

题库内容、官方资料链接和逐题对应见 [20 道教学题来源](2026-11-17_教学题库来源.md)。题库文件仍为 `Assets/StreamingAssets/Questions.json`，沿用原字段及从 0 开始的 `correct` 下标，可继续替换题目。

### 三工位的操作规则

演示采用当前正式控制流程：进入工位自动显示示教器，SELECT / F2 CREATE 新建，POINT 录点，TOUCHUP 补齐 C 终点或更新点位，SHIFT + FWD 运行，HOLD 暂停。L 是直线，C 使用上一条运动终点、圆弧经过点和终点。IO 不用于切换第三台留线状态。

- 第一台的评分与程序运行分开控制，步骤见 [Station1 轨迹评分](Station1轨迹评分.md)及 [循迹编程](Station1循迹编程.md)。
- 第二台的圆环和机械臂继续受钢丝与碰撞约束；第三台继续按真实笔尖高度留线，步骤见 [Station2/3 示教器编程](Station2和Station3示教器编程.md)。
- 本次没有改变速度、评分公式或工位分工。三台指令仍固定 **20 mm/sec**，没有调速入口。真实运动继续受原工位限制、IK 和碰撞检查约束。
