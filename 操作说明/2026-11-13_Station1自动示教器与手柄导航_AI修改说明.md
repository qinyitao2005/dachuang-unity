# Station1 自动示教器与手柄导航：AI 修改说明

> 本文记录 Station1 当时的修改。之后的 Station2 扩展见 [Station2 修改说明](2026-11-13_Station2自动示教器与手柄导航_AI修改说明.md)。

日期：2026-11-13。范围：Station1 循迹工位。Station2、Station3 的进入方式和操作界面保持原样。

## 这次改了什么

- 进入 Station1 工位后直接显示示教器和纸面俯视，不再出现原先右侧的末端点动菜单，也没有“收起示教器”按钮。
- “退出工位 [Esc]”按钮移到左侧循迹训练面板底部；键盘 Esc 仍可退出。
- Xbox Menu 在 SELECT PROGRAM 列表中退出工位；在编程、FCTN 等其他页面进入程序列表。程序运行中仍需先用 FCTN → 1 ABORT 终止，才能切换页面。
- Xbox View 短按在松开时发送 PREV。只在打开的程序编辑页持续按住 View 满 5 秒，才清空该程序的指令和点位并覆盖保存；长按不会先发送 PREV。程序名称和文件保留，清空不能撤销。这是供调试的隐藏操作。

## 从哪里打开、怎么操作

主场景：`Assets/RoboticsLab/Scenes/RoboticsTrainingRoom.unity`。完成安全帽、教学和问答后，靠近 Station1 按手柄 A 或键盘 E 进入，示教器自动显示。首次进入时显示 SELECT PROGRAM；如果当前会话已有打开的程序，重新进入可能回到该程序的编辑页。

1. 在 SELECT PROGRAM 按 B（F2 CREATE）新建，或十字键上下选已有程序、十字键右（ENTER）打开。
2. 在编辑页按 Menu 返回程序列表；在 FCTN 等子页面也可按 Menu 到程序列表。要回到编辑页，短按 View（PREV）。
3. 已在 SELECT PROGRAM 时按 Menu，退出 Station1 回到游荡；也可点击左侧“退出工位 [Esc]”或按键盘 Esc。
4. 完整 L/C 录点和运行步骤见 [Station1 Xbox 手柄操作](Station1_Xbox手柄.md)。
