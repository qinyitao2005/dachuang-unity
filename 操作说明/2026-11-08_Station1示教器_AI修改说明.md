# Station1 示教器：本次成果与 AI 修改说明

日期：2026-11-08。范围：主项目 Station1 的探针循迹示教器。

## 这次做了什么

把 Station1 已有的示教器编程改得更接近 FANUC 的常见操作，同时保留鼠标操作所需的简化。

- 加入 SELECT 程序列表、F2 CREATE、新建命名和打开已有程序。
- 复用现有工位隔离的程序存储，录点和修改后自动保存，重名不覆盖。Station1 文件在本机 Application.persistentDataPath/PendantPrograms/Station01，不会把每个人的练习点位上传 Git。
- F1 POINT 打开 L/C 菜单，ENTER 选择并录下当前位置；SHIFT + F1 重复当前格式录点。
- C 指令记录经过点和终点；SHIFT + F5 TOUCHUP 补终点或更新选中的点。C 行可以用左右键选择经过点/终点。
- 新运行从选中的程序行开始，HOLD 暂停、STEP 单步，FCTN 中的 ABORT 终止。RESET 用于复位已排除的故障，不再作为终止程序的按钮。
- 保留课堂流程：安全点 P[1] → 中间 L/C → 同一个 P[1]。在 End 输入 1、ENTER 可追加返回安全点的 L。
- 调整 LCD 底部软键标签、坐标和提示的区域，使用字号适配和裁切，处理文字挤在一起的问题；列表按实际文字高度滚动。
- 输入程序名时屏蔽点动和复位快捷键；上下左右方向键用于程序导航，WASD/QE 用于点动，避免锁定 SHIFT 后选行时误移动。
- 速度维持 20 mm/sec、FINE，没有加入调速入口；原工位上限和原手动点动速度保持不变。

## 怎么使用

完整步骤见 [Station1 循迹编程](Station1循迹编程.md)。最短流程是：

1. 完成安全帽、学习和问答的前置流程，进入 01 工位，展开示教器。
2. SELECT → F2 CREATE → 输入或接受程序名 → F1 END。
3. 点动到安全点，松开 SHIFT，F1 POINT 选 L，ENTER 录 P[1]；然后用 SHIFT + F1 继续录直线终点。
4. 到圆弧经过点，松开 SHIFT，F1 选 C、ENTER；再启用 SHIFT，到圆弧终点，F5 补齐终点。
5. End 输入 1、ENTER 返回原安全点；把光标移到第一条指令，SHIFT + FWD 运行。

例如屏幕显示 `C P[5] P[?]`，表示经过点 P[5] 已经录好，尚缺终点；移到终点后 SHIFT + F5。要改 P[5]，选该 C 行、按左箭头选择经过点，再移动到正确位置并 SHIFT + F5。

纸面循迹点的 Z 应接近 0；安全点至少高于纸面 5 mm。录点保存的是当前位置，回放按 L/C 重新生成路径，不会记住手动点动时绕过的整段路线。

## 当前简化与后续验收

固定探针姿态和 USER 平移坐标，没有实现完整 FANUC 的关节/工具坐标切换、姿态编辑和硬件使能回路。鼠标锁定 SHIFT、新建名称键盘输入、自动保存和 End 输入点号是便利功能。

新点目前只追加到 End；已有点用 TOUCHUP 修改。C 改 L 会拆为两条 L，L 改 C 暂时只支持末行且不能是首条安全点。J 参考线底部实际是椭圆形，分段圆弧只是近似；本次没有修改参考线形状。
