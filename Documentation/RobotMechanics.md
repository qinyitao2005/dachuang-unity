# 机械臂控制与练习参数

本轮新教学场景使用原工程的三套完整实训设备，保留机械臂、柜体、控制台、绿色框架及父子关节层级。下面的控制范围、工具约束和成绩指标都是本场景的训练参数，没有进行真实设备的运动学、碰撞空间或速度标定。

## 原设备来源与放置

原场景是 `Assets/Scenes/SampleScene.unity`。`LabOriginalEquipmentAssets` 提取以下三个完整设备组，保存为 `Assets/RoboticsLab/Generated/OriginalWorkcell1.prefab`、`OriginalWorkcell2.prefab`、`OriginalWorkcell3.prefab`，不会保存或覆盖原场景。

| 工位 | 原场景设备组 | 完整设备 MeshFilter 数 |
| --- | --- | --- |
| 1 | `多工位机器人集合/Draw` | 1751 |
| 2 | `多工位机器人集合/多工位实训平台 1` | 1751 |
| 3 | `多工位机器人集合/多工位实训平台 2` | 1751 |

统计包含非激活子对象，详见 `OriginalEquipmentInventory.txt`。设备网格来自原 `无标题.fbx`，继续使用其嵌入材质及原工程材质。每台以原尺寸放置，高约 2.124 场景米，设备根节点绕 Y 轴旋转 90°，使控制台朝过道。

原有 `IK`、`IKnew`、`IKnew2`、`AnimationEvents`、其他旧 MonoBehaviour 和 Animator 在提取副本中关闭，避免多个组件同时改动同一个关节。原代码仍保留。新组件 `RoboticsLab.LabRobotStation` 从原 `JointConfig` 读取关节和轴，用从腕部到基座的 CCD 迭代移动真实模型的 Transform。移动的是模型关节；笔和圈跟随实际末端，而不是直接跟随鼠标目标。

进入工位时，原轨迹模块暂时隐藏，但保留其对象和网格，并按所选模式显示绘图或套圈附件。退出工位后恢复原夹具；漫游时不显示练习板和圆环，避免新练习附件与原夹具互相穿插。

橙色货架来自原 `架子2.fbx`：入口右侧实例最长边约 3.8 场景米，后墙实例最长边约 6 场景米，均保持比例。完整来源与维护方式见 `原资产替换说明.md`。

## 相对初始姿态的关节范围

新控制器记录场景开始时每个关节的 localRotation，并把当时定义为偏转零度。当前范围如下：

| 关节位置 | 相对起始姿态的角度范围 |
| --- | --- |
| 配置数组第一个关节（底座） | -165° 到 +165° |
| 中间关节 | -100° 到 +100° |
| 配置数组最后一个关节 | -110° 到 +110° |

这些范围不等于具体品牌机器人手册中的绝对关节限位。组员接入完成的控制器界面时，可在生成脚本或 Inspector 中替换 `JointConfig` 的训练限位与轴配置。设备保留原尺寸，练习附件与工作范围按 `exerciseScale = 0.4` 调整；场景尺寸不直接当作真实设备的米制标定。

`MoveTool(Vector3 input)` 接收世界坐标 XYZ 方向，内部归一化到最大长度 1，再乘移动速度与 `Time.deltaTime` 一次。当前目标速度为 0.088 场景米/秒。它控制目标平移，不是工业机器人关节速度指令。`PositionError` 表示实际末端与目标的世界空间距离，可用于检查目标是否可达。急停禁止目标移动与关节求解；重置恢复起始关节姿态、工具目标、练习时间和计数。

## 练习缩放参数

`exerciseScale = 0.4` 用于练习附件和运动参数，不缩放完整设备。

| 参数 | 计算与当前值 |
| --- | --- |
| 目标移动速度 | `0.22 × 0.4 = 0.088` 场景米/秒 |
| 工作范围半尺寸 XYZ | `(0.33, 0.38, 0.48) × 0.4 = (0.132, 0.152, 0.192)` 场景米 |
| 圆环中心线半径 | `0.105 × 0.4 = 0.042` 场景米 |
| 环管半径 | `0.009 × 0.4 = 0.0036` 场景米 |
| 钢丝半径 | `0.007 × 0.4 = 0.0028` 场景米 |
| 有效落笔离纸容差 | `0.03 × 0.4 = 0.012` 场景米 |
| 绘图满进度累计长度 | `2 × 0.4 = 0.8` 场景米 |

## 绘图练习

选择绘图模式时显示绘图板。选择落笔后，目标移至纸面高度；只有实际末端距纸面不超过 0.012 场景米时才产生笔迹。笔迹使用实际末端的 X/Z 坐标，并投影到纸面；抬笔会结束当前笔画。

绘图 `Progress = Clamp01(累计有效笔迹长度 / (2 × exerciseScale))`，当前分母为 0.8 场景米。这是累计练习量，达到 100% 表示累计画了 0.8 场景米。它不表示形状准确率、工业轨迹精度或任务评分。清空/重置会清除笔迹及累计长度。笔迹顶点数随操作与采样变化，以本轮验证报告的实际记录为准，不作为固定验收数量。

## 钢丝套圈练习

选择套圈模式时显示钢丝与圆环附件。钢丝由 121 个采样点组成，在三个方向上弯曲。圆环中心线半径 0.042 场景米，环管半径 0.0036 场景米，钢丝半径 0.0028 场景米。环的中心跟随实际末端。

当前圆环采用 **passive swivel（被动转向接头）** 的仿真设定：环平面会依据当前所在钢丝段的切线自动调整，因此用户练习的是末端三轴平移，不需要另外手动控制工具姿态。这是界面未完成期间的训练辅助设定。组员若增加工具姿态控制，可替换 `UpdateToolVisuals()` 中的环朝向计算。

接触计算同时考虑环平面的轴向距离和环周的径向距离。套圈移动会拆成小步，检查钢丝穿过有效环孔及环管厚度，并截断向碰线或端点外的位移。求解关节后还会检查实际末端路径，越界则还原该步关节和目标，圆环仍跟随真实末端。此检查采用分段采样几何，不是工业级连续碰撞或完整机械臂自碰撞检测。

`Contacts` 在状态从未接触变为接触时增加 1，同一次持续接触不重复增加，并有 0.25 秒消抖。圆环接触时变红并阻挡继续越界，反向输入可以退回；起终点均限制向外位移。`Progress` 表示按顺序通过钢丝段的比例；必须从起点开始，钢丝位于环孔内且当前未接触才增加。完成后允许沿钢丝退回，进度保留已达到的最高值。重置把工具移回起点并清零接触次数、进度和时间。此次边界修复的验收状态见 `手臂放下与套圈边界修复.md` 与 `RingBoundaryValidation.txt`。

## 控制器接口与验证

后续示教器 UI 可以直接调用以下公开方法，不必重做房间、人物和安全准备流程：

- `BeginOperation()` / `EndOperation()`：开始或退出工位。
- `SetMode(0)` 绘图，`SetMode(1)` 套圈。
- `MoveTool(Vector3)`：每帧提交方向，调用侧不要再乘 deltaTime。
- `SetPen(bool)`、`ClearDrawing()`、`ResetExercise()`。
- `SetEmergencyStop(bool)`。

可读取 `IsOperating`、`EmergencyStopped`、`PenDown`、`TrainingMode`、`Progress`、`Contacts`、`Elapsed`、`ToolInContact` 和 `PositionError`。

进入工位应经过 `LabTrainingApp.TryStartStation()`，以复用安全帽、教学和问答检查。练习附件显隐随工位与模式切换，不要通过外部 UI 单独强制开启附件。
