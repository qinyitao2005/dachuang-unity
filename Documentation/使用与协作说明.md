## 打开与操作

- 双击工程根目录的 `Open Project.cmd`，使用本机 Unity 2022.3.61f1c1 打开；其他电脑可在 Unity Hub 中添加工程。
- 在 Unity Hub 中添加本工程目录，打开 `Assets/RoboticsLab/Scenes/RoboticsTrainingRoom.unity`，点击 Play。
- Windows 程序入口为工程根目录的 `Play Demo.cmd`，或 `Builds/Windows/RobotLab.exe`；Alt+F4 退出。当前展示版已通过运行回归、Windows 构建与独立启动检查，报告见下方。分享时发送 **整个 `Builds/Windows` 文件夹**，不能只发送 exe。普通试玩者不需要安装 Unity 或 MCP。
- 原场景保留在 `Assets/Scenes/SampleScene.unity`。新场景由 `Robot Lab > Build Teaching Room` 生成。此菜单会重建新教学场景；手工修改后不要随意再次执行，先另存场景。

角色使用第三人称视角。WASD 移动；移动鼠标直接转动视角；Tab 释放/重新捕获光标；滚轮调整距离；Shift 快走；走近设备按 E 交互；Esc 关闭面板/退出工位，漫游时也可释放光标；F1 查看说明。教学和工位界面会自动显示鼠标供点击，回到漫游后可按 Tab 恢复观察。

教学顺序：入口右侧领取并佩戴安全帽 → 右墙教学屏学习 → 在同一墙屏完成三道示例问答 → 左侧选择任一机械臂工位。

入口架上的四顶帽子都可以领取：走近想要的那顶，按 E 选择最近的可见帽子。拿蓝帽就戴蓝帽，拿白帽就戴白帽；只有选中的帽子离开货架，其他帽子保留。可领取范围外不会误拿远处的帽子。

走近右墙大屏按 E 后，镜头对准实际墙屏。视频、文字课程、问答、答案反馈和通过状态均显示在这块屏幕上，可以直接用鼠标点击屏幕内的播放/暂停、文字课程、开始问答、选项和下一题按钮。课程完成仅解锁问答，全部题目答完才解锁机械臂。按 Esc 或屏幕上的“退出学习”返回第三人称漫游。

靠近装备架按 E 后，人物会用约 3.1 秒完成托帽、举过头顶、戴稳和放下双手。动作期间锁定人物移动，完成后才解锁教学；重复按 E 不会重复领取。安全帽根据蒙皮后的头部表面校准位置与朝向，随头骨移动。

安全帽尺寸已统一：以已校准的头戴帽为准，同步入口货架上的四顶可选帽；货架、手持、头戴的实际几何尺寸一致，保留各帽颜色、朝向及托板贴合。后续重新校准人物时会同步更新货架帽，也可在停止 Play 后执行 Robot Lab > Match Shelf And Worn Helmet Sizes。

工位操作：WASD 水平移动末端；Q/E 升降；界面六向按钮可按住点动；P 抬笔/落笔；R 重置训练；空格或界面按钮触发/解除仿真急停；滚轮调整观察距离。进入工位时人物不响应移动，退出后恢复漫游。

进入工位时暂时隐藏原轨迹夹具，并按绘图或套圈模式显示对应练习附件；退出后恢复原夹具。漫游时不显示练习板和圆环，原设备对象与网格仍完整保留。

## 轨迹示教与指令展示

进入工位后点击“轨迹编程 / 示教 + 指令”，可用“示教点列表”记录当前位置，编辑每点的 X/Y/Z、速度与笔状态，并删除或调整顺序；也可在“指令编辑器”输入代码。坐标以当前工位练习中心为原点、单位为毫米；速度表示手动最高速度的百分比。蓝色折线只是目标预览，实际末端仍通过机械臂关节运动。

支持每行一条 `SPEED 1..100`、`PEN UP` / `PEN DOWN`、`MOVE x y z`、`WAIT 0..60` 指令，最多 256 步。`MOVE` 可带单点 `SPEED` / `PEN` 参数，便于从示教列表完整导出。落笔仅适用于绘图模式，点位 Y 必须位于纸面；优先点击“方形示例 / 三角示例”按当前工位生成，再修改。

修改代码后点“应用代码”，成功后才会更新运行程序；失败会提示行号并保留原程序。“从头运行”从第一步开始，“暂停 / 继续”保留当前位置，“单步”执行一条指令后暂停。运行或暂停时手动控制和编辑锁定，先点“停止”才能手动调整；“重置训练”复位工位但保留步骤。急停会暂停程序，解除后需点击继续；退出工位或切换模式会停止。文本框有输入焦点时，不触发 WASD、Q/E、P、R、空格快捷操作，急停可点击右侧按钮。

在名称框输入名称后“保存”，或用“已有文件”选名再“加载”。JSON 保存于 `%USERPROFILE%\AppData\LocalLow\Robotics Training Team\Robot Lab - Virtual Training\Programs`；本机是 `C:\Users\60200\AppData\LocalLow\Robotics Training Team\Robot Lab - Virtual Training\Programs`。这是用户数据目录，组员分享轨迹时需另带相应 JSON。加载按当前工位练习中心重定位，并重新检查范围。

此模块用于教学展示与组员联调，不连接真实机器人，也不是某一厂商的工业控制语言。详细入口、指令、保存方式和场景更新见 [展示版更新.md](展示版更新.md)。三台方形绘图程序、第一台完整套圈沿线程序及暂停、单步、急停、保存加载等检查均已真实执行通过，证据见 [TrajectoryProgramValidation.txt](TrajectoryProgramValidation.txt)；套圈转弯与边界结果及程序检查范围见 [套圈弯角与轨迹编程修复.md](套圈弯角与轨迹编程修复.md)。

## 控制器界面接入

保留原有 `Assets/Scrips` 和原场景。新增模块位于 `Assets/RoboticsLab`。新教学场景使用统一训练组件驱动完整设备副本内的机械臂层级；原柜体、框架和控制台随整套设备保留。提取副本中的旧行为脚本和 Animator 关闭，由新教学流程与训练组件接管输入和关节运动。

入口组件 `RoboticsLab.LabTrainingApp`：

- `TryStartStation(int index)`：按安全准备与问答状态检查权限并选择工位，数组下标从 0 开始。
- `ActiveStation`：当前选择的机械臂组件。
- `ClosePanel()`：退出工位并恢复漫游。

每个工位是 `RoboticsLab.LabRobotStation`，提供 `BeginOperation()`、`EndOperation()`、`MoveTool(Vector3 input)`、`SetMode(int mode)`、`SetPen(bool down)`、`SetEmergencyStop(bool stopped)`、`ResetExercise()`、`ClearDrawing()`。

控制器按住某方向时，每帧传入归一化方向向量，例如 `MoveTool(Vector3.right)`。不要在调用端再次乘 `Time.deltaTime`；工位内部负责速度与时间换算。模式 `0` 为绘图，`1` 为钢丝套圈。组员面板应通过 `TryStartStation` 进入，保留教学解锁条件。

运行状态可读取 `IsOperating`、`EmergencyStopped`、`PenDown`、`Progress`、`Contacts`、`Elapsed`。这套接口用于当前仿真与后续界面联调；涉及实际机械臂通讯或设备标定时需要另行适配。

## 练习指标与机械参数

完整模型来源、关节范围、末端运动、接触计算和 API 说明见 [RobotMechanics.md](RobotMechanics.md)。三个工位都使用原项目实际模型的关节层级，新的训练组件驱动真实的关节 Transform，绘图与套圈依据实际末端的位置计算。

- 当前关节范围相对保存的起始姿态定义：底座 ±165°、中间关节 ±100°、末端配置关节 ±110°。这些是场景训练范围，未作为具体设备的标定参数。
- 练习统一使用 `exerciseScale = 0.4`：目标移动速度 0.088 场景米/秒，圆环半径 0.042、环管半径 0.0036、钢丝半径 0.0028 场景米。此缩放仅用于练习装置与参数，完整设备保留原尺寸。
- 绘图进度按 **累计有效笔迹长度 / (2 × exerciseScale)** 计算，当前分母为 **0.8 场景米**，表示练习量，不能解释为形状准确率或工业轨迹精度。
- 圆环采用 **被动转向接头（passive swivel）** 设定，自动依据钢丝切线调整环平面。用户练习三轴平移；组员增加工具姿态控制后可替换这一辅助逻辑。
- 套圈进度按顺序通过钢丝段的比例计算；钢丝在环孔内且当前未接触时递增。碰线时会阻挡继续越界并使圆环变红，可以反向退回后调整路线；起点和终点限制向外移动，完成后仍可沿钢丝退回。一次持续碰线只计一次，另有 0.25 秒消抖。

戴帽放手与早期套圈边界修复记录见 [手臂放下与套圈边界修复.md](手臂放下与套圈边界修复.md)；本轮新增弯角滑动的结果以新的 [RingBoundaryValidation.txt](RingBoundaryValidation.txt) 及下方验证状态为准。
