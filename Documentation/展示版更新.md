## 鼠标与基本操作

漫游时移动鼠标直接转动视角，无需按住右键。WASD 移动，Shift 快走，滚轮调整距离。按 Tab 释放光标，再按 Tab 恢复鼠标转视角；漫游时 Esc 也会释放光标。教学屏和工位界面会自动显示光标供点击。

上述鼠标转向和光标切换策略已完成实现审核；未将该审核记为人工鼠标硬件实测。墙屏按钮已通过运行时屏幕射线命中与正常指针点击事件检查，见 `UserFlowValidation.txt`。

操作顺序仍为：领取并戴好安全帽 → 右墙课程与问答 → 选择工位。E 交互，Esc 关闭界面或退出工位；回到漫游后若光标仍处于释放状态，按 Tab 恢复观察。进入工位后 WASD 控制末端水平移动、Q/E 升降，P 抬落笔、R 重置，空格或右侧按钮急停。

## 示教点与指令编程

进入已解锁的机械臂工位，点击右侧“轨迹编程 / 示教 + 指令”。这个模块用于虚拟仿真的教学演示，不是具体品牌机械臂的工业编程系统，不连接真实设备。

“示教点列表”和“指令编辑器”共用同一个程序。坐标 X/Y/Z 是相对于当前工位练习中心的毫米值，速度是当前手动最高速度的百分比；蓝色折线表示目标轨迹预览，实际运动和笔迹仍由机械臂末端产生。

1. 在“示教点列表”中，先用手动按钮调整末端，再“记录当前位置”。选择某点后可修改坐标、速度和落笔状态并“应用到选中点”，也可删除、上移、下移。绘图模式提供“方形示例”和“三角示例”，会按当前工位生成纸面高度。
2. 点击“生成指令”，或切到“指令编辑器”。修改后必须点击“应用代码”，成功后才能运行或保存；解析失败会提示具体行，保留原程序。
3. “从头运行”从第一步开始；“暂停 / 继续”保留执行位置；“单步”执行一条指令后暂停。运行和暂停期间由程序控制机械臂，若要手动调整或编辑，先点“停止”。“重置训练”复位工位并保留程序步骤。
4. 急停会让程序暂停，解除急停后点击“继续”；退出工位、切换训练模式或复位会停止执行。无法到达或被边界持续阻挡时，状态区会指出步骤及原因。

在代码或数值框中输入时，WASD、Q/E、P、R 和空格作为输入内容，不触发相应快捷操作；需要急停时点击右侧急停按钮。关闭输入焦点后可继续使用快捷键。

| 指令 | 作用与范围 |
| --- | --- |
| `SPEED 60` | 设置后续速度百分比，允许 1–100 |
| `PEN UP` / `PEN DOWN` | 抬笔 / 落笔；落笔仅用于绘图模式 |
| `MOVE x y z` | 到达相对练习中心的指定毫米坐标，仍受工位范围与边界约束 |
| `WAIT 0.2` | 等待指定秒数，允许 0–60 秒 |

每条指令单独一行，可用 `#` 或 `//` 写注释。示教列表导出的 `MOVE` 行可带 `SPEED` 和 `PEN` 参数，保留每个点各自的速度与笔状态。最多 256 步；落笔点必须位于纸面，建议从界面生成的绘图示例开始修改。

套圈模式提供“沿线示例 / 沿线指令”。新版 [RingBoundaryValidation.txt](RingBoundaryValidation.txt) 已通过三台工位专项：碰线后单轴向前输入可沿外弯滑动，约 0.8 秒推进 49 毫米；交替单轴输入可完成全程 100%，碰线阻挡、反向退回和两端限位仍保留。

2026-09-25 的 [TrajectoryProgramValidation.txt](TrajectoryProgramValidation.txt) 已通过程序真实执行回归：三台机械臂分别完成 10 步方形程序，生成实际末端笔迹并在结束时抬笔；第一台的沿线程序通过实际 `Update → MoveTool` 完成全部 123 步，仿真用时 26.045 秒、套圈进度 100%、接触次数 0。暂停、单步、急停、退出工位、切换模式、示教点编辑、保存加载与错误行保留原程序均通过。详细结果见 [套圈弯角与轨迹编程修复.md](套圈弯角与轨迹编程修复.md)。三台套圈边界测试与第一台完整套圈程序测试是不同的检查范围。

## 保存、加载与分享轨迹

输入程序名称，点击“保存”写入 JSON。“已有文件”切换保存过的名称，选好后点击“加载”；加载时按当前工位练习中心定位。代码尚未应用或程序正在运行/暂停时，先应用代码或停止程序，再保存、加载和修改。

Windows 保存目录为：

```text
%USERPROFILE%\AppData\LocalLow\Robotics Training Team\Robot Lab - Virtual Training\Programs
```

本机对应 `C:\Users\60200\AppData\LocalLow\Robotics Training Team\Robot Lab - Virtual Training\Programs`。此目录来自 `Application.persistentDataPath/Programs`，不是工程 Assets 目录。组员分享自编轨迹时，将所需 `.json` 一并发送；接收方放入自己电脑对应的 Programs 目录后，在界面选择文件名并加载。程序名称和 JSON 有格式检查，报错时按状态提示修正。

## 执行与摄影入口

先停止 Play，打开 `Assets/RoboticsLab/Scenes/RoboticsTrainingRoom.unity`，执行：

1. `Robot Lab > Polish Training Room`：生成或更新 `RoomPolish`，只标记场景需要保存，留待检查后保存。
2. `Robot Lab > Capture > Room Polish Before And After`：暂时开关这一层，用固定摄影位生成前后对比。摄影范围为全景、教学区、入口和机械臂工位；结束后恢复原显隐状态。
3. `Robot Lab > Capture > Room Polish Current`：保留当前显示状态，拍摄相同四个摄影位。

图片输出到 `Documentation/Screenshots/RoomPolish_Before_*.png`、`RoomPolish_After_*.png` 或 `RoomPolish_Current_*.png`，每张为 1920×1080。这些照片用于场景视觉比较，不能替代真实人物移动和墙屏点击检查。
