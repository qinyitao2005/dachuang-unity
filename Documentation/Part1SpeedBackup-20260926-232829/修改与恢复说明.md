# 菜单速度设置更新
重新进入 Play 后，已有菜单自动增加“速度 0.10 / −0.05 / +0.05”一行，无需重新生成或手动拖引用。
初始速度 0.10，范围 0.00～0.50，每次点击增减 0.05，到上下限时对应按钮禁用。
手动移动、设定点及循迹使用原速度控制器的同一个 CurrentSpeed。循迹中也能调速。
0 表示暂停机械臂运动；增大速度后继续。允许以零速度进入循迹并等待加速。
原独立速度面板保留为备份资源，但 Part1 接入后不再弹出，自动回复原流程的速度完成信号。
新一轮 Play 使用 0.10；同一轮 Play 退出再进入时保留调节后的速度。

修改五份脚本：
- RobotTrajectoryMenu.cs：自动补充速度行和加减按钮，不重建已有 Canvas。
- Part1MenuAdapter.cs：连接速度控制器、加减事件和显示。
- 轨迹速度设置控制器.cs：菜单模式、整数档位、默认值与上下限、免输入完成流程。
- 机械臂XYZ手动移动控制器.cs：零速度停止 IK 追赶。
- 机械臂轨迹重复控制器.cs：零速度暂停及允许零速启动。

未改写场景、预制体、模型、材质或项目设置；285 个已有非脚本资源/设置文件 SHA-256 一致。
全 Assets 脚本编译通过；独立临时 Unity 项目 23 项检查通过。
未在用户完整工作场景中操作模型或进行视觉验证。

恢复本次更新：停止 Play，将本目录 Assets 下五份备份按同一路径覆盖回项目，即回到本轮修改前。
不要使用上一次 Part1MenuBackup 恢复本轮更新，否则会连之前菜单接入一起撤回。
