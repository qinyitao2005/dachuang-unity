# Station1 示教器循迹编程

主场景：`Assets/RoboticsLab/Scenes/RoboticsTrainingRoom.unity`。

本功能使用第一台机械臂的原装小探针。记录真实探针尖端的位置，用 L 直线和 C 三点圆弧循迹，最后返回自己示教的安全点，不生成新笔迹。

## 基本按键

| 按键 | 操作 |
|---|---|
| 示教器 | 展开/收起。展开时保留最左菜单，纸面俯视移至最右；收起停止程序并恢复布局，程序保留。 |
| SHIFT | 键盘 Shift 可按住使用。用鼠标时，点击示教器左右任意 SHIFT，绿色表示已锁定，用来模拟按住；再次点击松开。 |
| ±X / ±Y / ±Z（J1/J2/J3 所在的三行） | SHIFT 有效时按住点动，松开/移开鼠标停止。当前采用 USER 平移坐标：X 左右、Y 前后、Z 升降。也可 SHIFT 配合 WASD、Q/E。 |
| F1 POINT / F4 CHOICE | 未按 SHIFT 时 F1 打开运动类型选择；F4 随时打开选择。上下键选择 L 或 C，ENTER 确认，统一 20 mm/sec、FINE。 |
| SHIFT + F1 POINT | 记录当前真实探针位置。L 记录终点；C 先记录经过点。 |
| SHIFT + F5 TOUCHUP | C 未完成时补录终点；已有完整程序时，用上下键选中一行后更新它所引用的终点。 |
| 数字 + ENTER | 在 `[End]` 且当前类型为 L 时，追加一条引用已有点的 L。选中已有行时修改它的终点引用，也可补齐 C 的终点。 |
| SHIFT + FWD | 从头运行；HOLD 后继续。松开 SHIFT 会暂停；用鼠标锁定 SHIFT 时可以点击 FWD 运行。 |
| STEP | 切换单步模式，然后 SHIFT + FWD 执行一条完整的 L/C，再暂停。 |
| HOLD | 暂停，保留当前行和进度。 |
| RESET | 停止程序，保留点位和程序行。 |
| 急停按钮 | 急停/解除。解除后仍需 SHIFT + FWD 明确继续。 |
| FCTN | 上下键选择“删除最后一行”或“清空/新建程序”，ENTER 确认。 |

POINT、CHOICE、TOUCHUP、SHIFT 和 FWD 参照 FANUC 常见示教方式。本教学版本保留固定探针姿态及当前 USER 平移坐标，未实现完整工业控制柜的关节/工具坐标切换、姿态编辑和硬件使能回路。SHIFT 鼠标锁定是为了单鼠标操作组合键而提供的模拟功能。

LCD 坐标以纸面中心为 USER 原点，X/Y 表示纸面位置，Z 表示离纸高度，单位 mm。例如安全点在纸面上方 18 mm 时，Z 应约为 18。

## 安全点与返回

第一条指令必须是 `L P[1]`，P[1] 是自己记录的安全点，须至少高于纸面 5 mm。建议选在循迹起点正上方，约 18 mm 的高度处。

按课堂流程，程序是“安全点 P[1] → 中间 L/C 轨迹 → 同一个安全点 P[1]”。到安全点和返回安全点统一使用 L 直线移动。

在程序末尾选 L，在 `[End]` 输入数字 1 后按 ENTER，追加 `L P[1]`，相当于复用开头记录的安全点。返回前不要求再录一个等高的离开点；最后一条 L 会从上一条轨迹的终点直线移动到已保存的 P[1]。返回继续经过原 IK、工作区和碰撞检查。

录点只保存当前位置，不会自动替你移动到下一个点。C 的起点是上一条指令的终点，经过点不是圆心。未完成或退化的圆弧会被拒绝。程序运行/暂停时，手动点动和编辑均锁定。

## 一个可按按钮完成的示例：两段圆弧循迹一个圆

先在最左菜单选圆形，再展开示教器。

1. F1 打开运动类型选择，选择 L，ENTER。点击 SHIFT 锁定。
2. 点动到圆形绿色起点正上方，保留约 18 mm 高度；SHIFT 有效时点击 F1，得到安全点 P[1]。
3. 向下点动到纸面起点，再点击 F1，得到 `L P[2]`。
4. 点击 F4，选择 C，ENTER。沿圆的顺序，点动到第一段半圆的经过点，F1 记录 P[3]。
5. 移到对面半圆终点，F5 补录 P[4]，形成第一条完整 C。
6. 点动到另一半圆的经过点，F1 记录 P[5]。直接按数字 2、ENTER，复用 P[2] 作为第二条 C 的终点。
7. 点击 F4 选择 L，ENTER。在 `[End]` 按数字 1、ENTER，追加 `L P[1]`。
8. SHIFT 保持有效，点击 FWD。机械臂先到安全点、下降到起点，执行两段圆弧，最后升回安全点。

屏幕中的程序为：

```text
1:L P[1] 20mm/sec FINE
2:L P[2] 20mm/sec FINE
3:C P[3] P[4] 20mm/sec FINE
4:C P[5] P[2] 20mm/sec FINE
5:L P[1] 20mm/sec FINE
[End]
```

每个 C 在列表中合写为一行，表示经过点和终点共同组成一条指令。末端实际经过参考线才计入循迹成绩；安全点、接近和返回的离纸运动不计入纸面覆盖率。

## 验收

- 实际按钮变色，LCD 显示所选类型、点号、程序行、SHIFT/STEP 状态、坐标和运行信息。
- 观察实际探针尖端走出直线/圆弧并返回 P[1]，纸面不生成新笔迹。
- 验证 HOLD、SHIFT 松开、急停及关闭示教器都能停止或暂停运动，解除后需明确继续。
- Editor 菜单 `Robot Lab > Diagnostics > Validate Station1 Programming` 可运行自动验收，结果写入 `Documentation/Station1ProgrammingValidation.json`；会进入 Play Mode，并在内存中临时解锁工位用于测试。

资料：[FANUC HandlingTool Setup and Operations Manual，§7.2](https://studylib.net/doc/27738778/r-30ib-plus-handlingtool-operator-manual)。具体软键名称随控制器版本和当前页面变化。
