仓库原版本记录为 Unity **2022.3.62f3c1**；本次实际验收使用 **2022.3.61f1c1**，两者均属 Unity 2022.3 LTS 的不同补丁版本。入口场景为 `Assets/RoboticsLab/Scenes/RoboticsTrainingRoom.unity`。建议组员统一到实际验收所用的编辑器版本。

验证记录见 `Documentation/DedicatedStationValidation.txt`、`TracingValidation.txt`、`BuildReport.txt` 和 `StandaloneSmoke.json`。本版将第一台改为原装笔形探针、循迹不留新线；验收需核对报告中的工具类型、零循迹笔迹与第三台绘图检查，不能直接沿用旧版夹爪的通过结果。

原装探针版已重新通过 Editor **67/67** 项运行验证：28 个原始网格保持刚性、实际针尖轴竖直、四个自动图形与手动 J 完成评分且全程零 `DrawingStroke` 对象；第三台仍能生成真实绘图笔迹。Windows 重新构建成功，错误和警告均为 0。

新版 Windows 独立运行也已通过：`passed`、`tracingNoInk`、`drawingInk` 均为 `true`，四条自动路径覆盖率 100%，本次得分 99.93～99.97，循迹笔迹顶点数均为 0。原探针资产预览见 `OriginalTracingProbeAsset.png`，实际装配画面见 `StandaloneTracingWorkcell.png`。

## 打开交付包

源码包 `RobotLab_Source.zip` 完整解压后，用 Unity Hub 添加包含 `Assets`、`Packages`、`ProjectSettings` 的工程根目录，再打开入口场景。源码包含原资产、全部 `.meta`、教学视频、题库和本地 MCP 包；首次打开会重新生成 `Library`。`Open Project.cmd` 使用固定的本机编辑器路径，组员电脑路径不同时直接使用 Unity Hub。

Windows 包 `RobotLab_Windows.zip` 完整解压后，直接双击 `RobotLab.exe`；它与 `RobotLab_Data`、`UnityPlayer.dll` 等文件需保持在一起。源码根目录的 `Play Demo.cmd` 适用于本地 `Builds/Windows` 构建目录；单独运行包直接打开 exe 即可。

## 进入工位

先完成安全帽、墙屏学习与问答，再走近工位按 **E**。漫游时用 WASD 移动、鼠标转视角、Tab 释放光标。01 工位采用面向纸面的视角，绿色圆点标记各图形起点，蓝色线表示当前选择。

循迹工位默认并排显示机械臂动作和**纸面俯视图**。俯视图不受机械臂遮挡：蓝色为当前参考线，橙色十字为真实探针位置；空心表示未开启触纸采样。纸面和俯视图均不生成新线。图形保持纸面 X/Z 的相同比例，W/+Z 向上、D/+X 向右。可用“收起纸面俯视 / 展开纸面俯视”切换显示，切换不会暂停或重置练习。俯视图只读实际状态，不改变模型、IK 或碰撞。

## 手动 J 型

1. 在 01 工位选择“J 型 · 手动循迹”。抬起探针，移动到 J 型绿色起点的上方。
2. 点击“开始手动 J”。探针贴向纸面，按印刷参考线顺序移动，不留新线。
3. WASD 控制纸面 X/Z 方向；Q/E 升降；P 切换探针抬起或贴纸。贴纸时目标高度固定在纸面，按探针实际接触状态采样。
4. 走完后自动结算，也可以点击“结束并评估”提前结束。未走完的部分会降低覆盖率和总分。

“重新开始手动 J”会清除本次成绩。**R / 重置成绩**清除尝试并退出触纸采样，不把机械臂瞬间送回起点；先抬起探针，重新移至绿色起点再开始。

## 四个自动图形

选择圆形、三角形、正方形或复合曲线，点击“开始自动循迹”。机械臂会抬起探针、移至所选起点、贴纸并沿完整印刷图形行走，全程不留新线。复合曲线按照片轮廓制作：左侧上升弧线、内凹曲线、右侧斜边、竖边和底边闭合。

自动运行时手动移动锁定；可以停止、重置或急停。成功程度按实际探针运动计算，程序执行结束不直接视为满分。若碰撞检查、关节范围或工具姿态阻止到达目标，自动流程停止并显示原因。

**空格急停**、**F1 帮助**或 **Esc 退出**都会终止当前尝试，包括手动 J 和自动图形。旧成绩保留至重置或开始新尝试；解除急停或从帮助返回不会续接未完成的尝试。再次点击开始会清空旧成绩并重做，手动 J 需先抬起探针移回绿色起点。

## 成功程度怎么算

评分仅使用实际探针在纸面上的触纸轨迹，不使用目标点代替真实位置，也不依赖可见笔迹。

- **覆盖率**：按照路径顺序经过的检查点占总路径长度的比例。单纯靠近任意一段、抬起探针跨越或瞬移不能跳过中间检查点。
- **精度**：每段实际移动的精度为 `clamp(1 − 偏差 / 容差, 0, 1)`，再按移动距离加权平均，显示为百分比。偏差是实际探针到参考线的最近距离。默认容差 **3 mm**；偏差 0 mm 对应 100%，偏差 1.5 mm 对应 50%，达到 3 mm 对应 0%。
- **成功程度**：`覆盖率 × 精度 / 100`，范围 0～100 分。例如覆盖率 80%、精度 90%，总分 72。
- **平均偏差**按实际移动距离加权，单位 mm；当前偏差是最新探针位置到参考线的距离。停在原地不会提高成绩。

这是虚拟教学的评分规则，用于比较练习完成程度，**不是工业机械臂的精度检测或认证结果**。
